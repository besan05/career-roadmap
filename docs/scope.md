# Scope

## The limits

Every plan, requirement and decision in this project must fit inside these:

- **Time:** 8 weeks, one session a week, plus 3–8 hours between sessions.
- **People:** one person building, not a team.
- **Money:** the app costs $0. The AI runs on Gemini's free tier with no billing attached. No paid hosting, storage, email or APIs. (My own AI subscription is used only for drafting, never by the app.)
- **Demo:** it has to run and be shown live on the final night.

If an idea does not fit, say so and say what to cut. Do not quietly shrink it.

## In

1. **Accounts:** sign-up with email, password, a single-use invite code and a consent tick, for 5 invited students.
2. **A 10-day plan per student:** generated by the AI inside the app from a pasted job posting, checked before saving, with role templates as the fallback.
3. **Daily micro-tasks** (about 30 minutes each), unlocked in sequence by submitting an evidence link.
4. **A read-only view for the creator** to see every student's progress and evidence. Everything else the creator does is a command-line script.

## Out, and why

| Not building | Why it is out |
|---|---|
| Open sign-up without an invite code | The test is limited to students I invite, and the AI's free tier is limited. |
| Password reset by email, Google sign-in | Needs an email service. A student who forgets their password asks me, and I set a temporary one with a script. |
| Login attempt limits, invite code expiry | The test is 5 invited students over a few weeks. Recorded as a known risk in D52. |
| Plans tailored by country | Needs market data per country. A posting from the student's own country already makes the plan local. |
| Paid AI, or attaching billing to the free tier | Breaks the zero-cost limit. If the free tier fails, students get a template. |
| Skills assessment, quizzes or self-rating | Out of scope in the brief. The posting or template defines the path. |
| Image or file uploads | Needs file storage. Evidence is links only. |
| Notifications, emails, reminders | Needs a sending service and extra work. The app waits quietly. |
| Admin dashboard (creating codes, editing plans, unlocking days) | Done with command-line scripts. Only one read-only page for the creator. |
| Automatic checking or AI grading of evidence | The creator reviews the work. Any valid link unlocks the next day. |
| Regenerating or editing a plan after day 1 | Would change or delete submitted work (N3). |
| Hint or "unstuck" button | Not in the brief's two core components. |
| Points, badges, streaks | Not part of the evidence loop. |
| Mobile app or mobile-optimised layout | Students code on laptops. Desktop browser first. |
| Arabic or multiple languages | English only, matching the tools students work in. |
| Calendar-based schedule or deadlines | Days unlock by completion, not by date. |
| Mentor network | Deferred until after the 8 weeks. A second project in itself. |
| Mock interviews, job placement, hiring pipeline | Out of scope in the brief. |
| Market data collection or analysis | Cannot be curated by one person in 8 weeks. Job postings are the input. |
| Payments | Free for testers. |
