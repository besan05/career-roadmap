# Research: Existing Alternatives

Three tools students already use to get job-ready. Prices checked October 2026 (USD, US pricing; local pricing may differ).

## 1. ChatGPT

| | |
|---|---|
| **Who it is for** | Everyone. A general-purpose assistant with no career-specific focus. |
| **What it does well** | Turns any job posting into a plausible study plan in seconds. Explains errors and concepts on demand. Free and already open on every student's laptop. |
| **What it misses** | The plan is a one-off answer. Nothing tracks whether day 3 was done, nothing asks "where are you?" when a student goes quiet, and nothing requires proof of work. The student has to remember to come back and drive every step. |
| **What it costs** | Freemium. Free $0; Go $8/month; Plus $20/month. |

**Do not reinvent:** plan generation and on-demand explanations. Use an LLM for these rather than building them by hand.

## 2. roadmap.sh

| | |
|---|---|
| **Who it is for** | Developers; it describes its content as helping them "choose your path and grow in your career." |
| **What it does well** | Community-maintained, role-based roadmaps (frontend, backend, DevOps, AI engineering and more), project ideas, best-practice guides, and progress tracking for signed-in users. |
| **What it misses** | Roadmaps are generic per role, not built from a specific job posting. They map the whole field (months of topics) rather than a 14-day path to one project. Tracking is self-reported ticking, with no proof of work and no follow-up when a student stops. |
| **What it costs** | Freemium. Roadmaps are free; an account upgrade unlocks premium AI features. |

**What I saw when I tried it:** (fill in after using it for 10 minutes)

**Do not reinvent:** the topic map for each role. Link to roadmap.sh for "learn more" instead of writing our own reference content.

## 3. Coursera Professional Certificates (and YouTube courses)

| | |
|---|---|
| **Who it is for** | Learners seeking job-ready skills for entry-level roles, through employer-designed certificates (e.g. Google, IBM, Meta). |
| **What it does well** | Structured, high-quality content with graded assignments, hands-on projects and a recognised certificate that shows on LinkedIn. YouTube adds free, unlimited tutorials. |
| **What it misses** | Designed for months of study (typically 3–6 months at several hours per week), not a short sprint. Content is the same for every learner and not tied to the posting the student wants. Completion depends on self-motivation, which is exactly where our users stop. |
| **What it costs** | Freemium. Many courses free to audit; Professional Certificates from about $49/month; Coursera Plus $59/month or $399/year. YouTube is free. |

**Do not reinvent:** teaching content. Our tasks should point to existing free lessons rather than host our own.

## Summary

| | Tied to a real posting | Short, project-sized plan | Daily 30-minute tasks | Proof of work required |
|---|---|---|---|---|
| ChatGPT | Yes | Yes | Only if asked | No |
| roadmap.sh | No | No | No | No |
| Coursera / YouTube | No | No | No | Partly (graded assignments) |
| **Ours** | **Yes** | **Yes** | **Yes** | **Yes** |

## Why ours instead?

**ChatGPT, roadmap.sh and Coursera all hand the student a plan and leave execution to them; ours turns one real job posting into 14 daily 30-minute tasks, and a day only counts once the student uploads code or a result, so progress reflects work actually done.**
